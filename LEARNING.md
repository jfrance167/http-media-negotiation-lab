# Learning

Specificity assigns each candidate its governing quality; it does not generally break equal-quality ties between candidates. A specific q=0 exclusion must defeat a broader positive wildcard for that candidate. Keeping equal-best IDs separate from server policy makes that distinction observable.

A complete expected report tests provenance, unsupported handling and policy as well as numeric quality. Mutation tests caught quality-before-specificity, treating zero as eligible, omitting the format tier and breaking candidate ties by range specificity. Passing fixtures alone would not establish broader conformance.

The first implementation run exposed a contract ambiguity: a parameter dictionary at container depth eight has scalar leaves one level deeper. Define container depth explicitly, retain the original freeze and explain corrections rather than silently updating history.

Windows text streams translate LF to CRLF. Fixed byte-level diagnostics require binary writes. Closed operating-system pipes and closed Python streams are different failure mechanisms; controlled short-write, flush and close mocks are useful seams but must not be described as physical failures.

The first full verifier failed compilation when its relocated bytecode cache could not be created. Compile using the normal local cache; retain fresh cache isolation and disabled bytecode writes for mutated child runs. Do not infer an OS-wide diagnosis from this one failure.

An admitted stress document can still exceed the report cap after Markdown escaping. The tested 18-case input was 60,367 bytes; Markdown measured 628,849 bytes and was correctly rejected at the ordinary 524,288-byte cap. This proves reachability, not a maximum possible output.
